About Me

Hi! I'm Constante C. Dizon II. Pretty long name, huh? You can call me Constante, or whatever you feel comfortable with, as long as I recognize it.

I'm a Computer Science graduate specializing in Data Science, pursuing a career in Data Engineering. I enjoy building reliable data systems, ETL workflows, backend solutions, and applying machine learning to real-world problems.

I've always been a data person — SQL rows, Excel rows, and probably more rows than I can count. I enjoy cleaning, organizing, and transforming messy data because every inconsistency tells a story waiting to be understood.

From automating workflows to preparing datasets for machine learning models, I find value in turning raw data into something reliable. Sometimes, after hours of cleaning data, seeing a model output "90–95% accuracy" is the reward — even if that number raises more questions than answers.

Because at the end of the day, data is more than rows and numbers — it's the foundation behind every system, decision, and solution we build.
